# 색면화 좌대 · 인식과 송출 설정

좌대 제작안: https://saekmyeon-pedestal.oho-77.workers.dev (600 × 600 × 900, 상판 포켓, 내부 PC)

## 동작

1. 캔버스(4호 S, 242 × 242) 틀 아랫면에 붙인 NFC 태그를 상판 아래 RC522가 읽습니다.
2. 아두이노가 USB 시리얼로 `TAG <UID>`(올림) · `NONE`(내림)을 보냅니다.
3. 좌대 안 PC의 크롬에서 색면화 페이지가 이 신호를 받아, 등록된 작품의 입자·음악을 내보냅니다. 내리면 0.8초 뒤 쉬는 화면으로 돌아갑니다.

## 준비물

| 부품 | 내용 |
|---|---|
| 리더 | RC522 (13.56 MHz, ISO14443A) |
| 보드 | Arduino Uno + USB 케이블 (PC와 연결) |
| 태그 | Ø38 NFC 스티커 8장 (NTAG213/215). 작품마다 1장 |
| PC | 데스크톱(좌대 안), 크롬. 프로젝터 2대 연결(화면 확장) |

## 배선 (RC522 → Uno)

| RC522 | Uno |
|---|---|
| SDA(SS) | D10 |
| SCK | D13 |
| MOSI | D11 |
| MISO | D12 |
| RST | D9 |
| 3.3V | 3.3V (5V 금지) |
| GND | GND |
| IRQ | 연결 안 함 |

## 아두이노

1. Arduino IDE → 라이브러리 관리자에서 `MFRC522`(miguelbalboa) 설치
2. `saekmyeon_reader/saekmyeon_reader.ino`를 Uno에 업로드
3. 시리얼 모니터(115200)에서 태그를 대면 `TAG 04…`, 떼면 `NONE`이 나오는지 확인한 뒤 시리얼 모니터를 닫습니다. 열려 있으면 크롬이 포트를 쓸 수 없습니다.

## 태그 등록 (처음 한 번)

1. 좌대 PC의 크롬에서 색면화 페이지를 열고 「좌대 인식 → 리더 연결」을 누른 뒤 Arduino 포트를 고릅니다. 한 번 허락하면 다음부터 자동으로 연결됩니다.
2. 「태그 등록」을 켭니다.
3. 캔버스를 하나 올리고, 목록에서 그 작품 옆 「등록」을 누릅니다. 8점을 반복합니다.
4. 「태그 등록」을 끄면 바로 운영 상태가 됩니다. 등록 내용은 그 PC의 크롬에 저장됩니다.

## 송출

- 페이지의 「송출 화면 · 프로젝터 2대」: 화면 왼쪽 절반 = 프로젝터 ①(정면 벽), 오른쪽 절반 = 프로젝터 ②(오른쪽 벽). 윈도우 디스플레이 설정에서 프로젝터 ①을 왼쪽, ②를 오른쪽에 두고 크롬 창을 두 화면에 걸쳐 띄웁니다.
- 각 벽 그림은 벽 비율(정면 7.39 : 3.3, 오른쪽 5.45 : 3.3)대로 화면 안에 들어가고 남는 곳은 검정입니다. 현장에서 프로젝터 줌·위치로 벽에 맞춥니다.
- 주소로 바로 열기: `…/colorfield/?output=2` (한 화면은 `?output=1`). Esc로 나가고, O 키로 들어가고 나옵니다.

### PC가 켜지면 자동 실행 (윈도우 예)

시작프로그램에 바로가기를 만들고 대상에 아래를 넣습니다. `--autoplay-policy` 덕분에 클릭 없이 소리가 납니다.

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required --window-position=0,0 --window-size=3840,1080 "https://khyun024.github.io/hamkke-808-sim/colorfield/?output=2"
```

창 크기는 두 프로젝터 해상도의 합에 맞춥니다(1920×1200 두 대면 3840,1200).

## 확인할 것

- **판독 거리**: 태그와 리더 사이가 상판 포켓 바닥 15 mm입니다. RC522 기본 안테나로 Ø38 태그는 대체로 2~4 cm까지 읽히지만, 실제 합판·도장으로 꼭 시험해 보세요. 안 읽히면 포켓 바닥을 얇게 하거나(최소 3 mm), 태그를 키우거나(Ø50), 리더를 포켓 바로 아래에 붙입니다.
- **금속**: 리더 주변 5 cm 안에 금속(경첩, PC 케이스, 철제 브라켓)이 있으면 판독 거리가 크게 줄어듭니다.
- **태그 위치**: 캔버스를 돌려서 올려도 태그가 리더 위에 오도록, 리더를 포켓 중앙 쪽에 두거나 태그를 틀 네 귀퉁이 중 리더 위로 오는 자리에 붙입니다.
- 리더 없이 시험할 때는 숫자 1~8(작품), 0(빼기), S(소리), O(송출 화면) 키를 씁니다.
