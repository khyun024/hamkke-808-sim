2. 콘셉트 한 줄

참여자의 색면화가 벽만큼 커져서 숨을 쉰다. 캔버스를 좌대에 올리면 그 그림의 색면이 좌대 쪽 벽에서 모서리를 돌아 오른쪽 벽까지 물감처럼 번져 나간다. 색과 비례는 원작 그대로 두고, 띠의 경계가 물결치고 색면 안에서 빛의 결이 흐르는 정도만 움직인다. 그 위로 아주 적은 빛 먼지가 떠돈다. 음악은 그 참여자의 애장품 이야기로 만든 2분 연주곡이고, 저음·악센트·음역이 화면의 파도와 밝기를 움직인다.

  • 지키는 것: 원작의 색, 띠의 순서와 비례, 손으로 그은 경계의 울퉁불퉁함.
  • 움직이는 것: 경계 위를 지나는 긴 파도(벽에서 약 35 cm/초), 색면 안 빛의 결(±16%), 띠 두께의 숨(±10%), 음악에 따른 밝기.
  • 하지 않는 것: 그림을 가루로 흩뜨리거나 다른 모양으로 바꾸는 것. 글자·캡션(설명은 사이드 벽 패널이 맡는다).

3. 작품 8점 · 이야기 · 음악

번호는 재단 개요 표 순서 = 페이지 썸네일 순서(숫자 키 1~8). 이야기와 찾은 색은 재단 개요 그대로. 음악은 2판(11-09, 공통 팔레트: 펠트 피아노·따뜻한 현·유리 질감). 반응 지표는 프리비즈에서 곡을 틀고 23초간 잰 값(0~1, 클수록 화면이 많이 움직임). 〈아빠〉〈나〉는 고음 범위와 악센트 문턱을 고친 뒤 다시 잰 값이고, 나머지는 고치기 전 값이라 지금은 조금 더 높게 나옵니다.

번호캔버스작품 · 애장품 이야기찾은 색음악 (조성 · 빠르기 · 악기)듣기반응 지표

〈나이키 운동화〉는 개요의 제목과 설명(농구공)이 서로 맞지 않습니다. 패널 문구를 확정할 때 재단에 확인합니다.

4. 음악 ↔ 화면 상호작용 규칙

음악에서 읽는 것화면에서 일어나는 일세기 · 시간
저음(30~170 Hz)띠 경계의 파도가 높아진다최대 +35% · 부드럽게 따라감(반응 부드러움 60%)
악센트(스펙트럼이 갑자기 커지는 순간)빛 물결 머리에서 넓은 빛이 번져 양옆으로 퍼진다1.1초에 한 번까지 · 9초간 사그라듦 · 6초 넘게 조용하면 문턱이 내려가 희미한 곡에서도 가끔 생김
음역(70 Hz ~ 4.5 kHz를 띠 수만큼 나눔)위 띠는 높은 음, 아래 띠는 낮은 음에 밝아진다최대 +35% 밝기
고음(1.5~7 kHz)빛 먼지 일부가 느리게 반짝인다먼지 10%만
전체 음량색면 전체 밝기와 먼지 흐름 속도가 조금 오른다+6% · +25%
곡의 네 마디빛 물결이 시작 벽에서 끝 벽까지 한 번 지나간다 (그림을 올린 순간부터)〈결혼식〉 63 BPM 3/4 = 11.4초, 〈아빠〉 56 BPM 4/4 = 17.1초
그림을 올림 · 바꿈 · 뺌음악이 2초에 차오르고, 바꾸면 2.5초에 잦아든 뒤 다음 곡이 시작. 색면은 같은 방향으로 번지고 풀어짐두 곡이 겹치지 않음

곡마다 다이내믹이 달라서 〈선생님〉〈아빠〉〈나〉는 반응 배율을 1.3~1.4로 올려 두었습니다(페이지의 WORKS[].rx). 조절 패널 「소리 반응」에서 전체 세기를 바꿀 수 있습니다.

5. 만드는 순서 (기획 → 음악 → 미디어아트)

  1. 기획: 이 문서의 3번 표가 기준입니다. 작품 이야기·찾은 색·음악 콘셉트가 바뀌면 여기부터 고칩니다.
  2. 음악 생성: sound/README.md의 프롬프트(작품별 앞부분 + 공통 꼬리말)로 ElevenLabs Music에 2분 연주곡을 요청합니다. 곡당 약 1,650 크레딧, 한 곡씩 20초 간격. 받은 파일은 앞뒤 무음을 잘라 -18 LUFS로 맞춰 sound/cfN.mp3로 넣습니다. 파일만 바꾸면 페이지는 그대로 씁니다.
  3. 미디어아트 반영: 페이지 WORKS에 그 곡의 조성·BPM·박자를 적습니다(네 마디 빛 물결 주기와 실시간 합성음이 여기서 나옵니다). 다이내믹이 작은 곡은 rx를 올립니다.
  4. 점검: 프리비즈에서 소리를 켜고 그림을 올린 뒤 콘솔 cfAR.v(저음·고음·음량)와 cfAR.k(악센트 수)를 봅니다. 저음·음량 평균 0.35 이상, 악센트 10초에 2회 이상이면 반응이 보입니다.

6. 현황 · 남은 일

되어 있는 것

  • 캔버스 사진 8점(〈너부리〉는 11-09 단체 사진에서 잘라 넣음)
  • 음악 2판 8곡(-18 LUFS, 89~120초, 공통 팔레트)
  • 색면 방식 프리비즈(① 물결치는 경계 기본, 안 ②~⑥ 프리셋)
  • 투사면 두 면(정면 + 오른쪽) 재단 확인 완료
  • 좌대 NFC 인식(Web Serial), 송출 화면 ?output=2, 설치 체크리스트

확인·결정할 것

  • MP-V5002로 바뀔 경우 색면화 방 프로젝터 거리 재계산(설치업체)
  • 〈나이키 운동화〉 제목·설명 불일치 → 재단
  • 음악은 사람이 들어 보고 확정(파도 속도·잔상은 현장에서 조정)
  • NFC 태그 8장 등록, 좌대 제작 완료 확인
